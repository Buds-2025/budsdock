# 1.0.1验收入口

当前版本的构建、发行包和真实WPF集成验证使用项目`scripts/verify_release.ps1`。该脚本运行45项回归测试，并检查Portable、Compact两种发行包的深色中文与浅色英文界面。运行之前先按README发布两种版本。

本版新增手工检查：在不同缩放比例的显示器之间拖动；跨较小屏幕后确认位置；断开并重新连接显示器；同屏和其他屏幕分别进入全屏；搜索后添加文件夹；对EXE、LNK、自定义图片验证列表与详情异步刷新；使用鼠标和键盘调整图标顺序。旧配置的Tile、Monochrome模式应转换为原图，设置中不应再显示两组外观选择。

结果与未验证边界见`UPGRADE-1.0.1.md`。以下为原版历史检查清单，涉及已移除的图标外观模式时以1.0.1说明为准。

# BudsDock 1.0.0验收清单

## 自动化结果

运行命令：

```powershell
dotnet run --project .\tests\BudsDock.Tests\BudsDock.Tests.csproj -c Release -p:Platform=x64
```

当前共45项，应全部通过。覆盖范围包括：

1. 五种预设定位、底部2.5倍任务栏高度间距、横纵方向切换、工作区边界和自定义位置钳制。
2. 全部外观边界、默认图标外观、当前图标与两级邻居倍率、图标取色发光、极端缩放光晕安全边距、动画关闭回退。
3. 异步命令防重复、防抖保存、保存成功与失败状态。
4. `Items=null`、非法枚举、损坏配置、未来版本配置及恢复副本。
5. 配置包图标携带、导入事务回滚和订阅者异常隔离。
6. 中英文资源键一致、主题对比度和关键XAML交互约束。

WPF绑定冒烟测试：

```powershell
$env:BUDSDOCK_DATA_DIR="$PWD\.ui-test-data\smoke"
.\src\BudsDock\bin\x64\Release\net10.0-windows10.0.22621.0\BudsDock.exe --smoke-test
```

诊断模式使用独立互斥锁和数据目录，可与日常实例并存。`binding-errors.log`必须为空，进程退出码必须为0。

## 手工验收

### 启动与基础显示

- [ ] 在无.NET运行时的x64 Windows 11电脑解压便携包并启动。
- [ ] 首次出现五个系统图标：我的电脑、控制面板、资源管理器、Edge、回收站。
- [ ] 五个系统目标均可单击打开。
- [ ] 第二次启动不会出现两个Dock实例。

### 图标管理

- [ ] 从设置页添加EXE和LNK。
- [ ] 将EXE或LNK拖到Dock空白区域可添加。
- [ ] 重复拖入相同路径不会重复添加。
- [ ] 设置页上移、下移顺序实时反映到Dock。
- [ ] 移除项目不会删除原程序。
- [ ] 导入PNG、JPG、BMP、GIF、ICO后，移动源文件不影响显示。
- [ ] 图标统一使用原图，旧配置中的底片和单色模式自动迁移。
- [ ] 启动参数、工作目录和管理员运行开关生效。
- [ ] 目标文件与工作目录可通过浏览按钮选择，工作目录可清除。
- [ ] 640×480和820×540下点击已选中的首项仍能打开详情，并可使用“返回列表”返回。
- [ ] “尚未添加程序”和“已有项目但未选择”两种空状态分别正确显示。

### 外观

- [ ] 深色、浅色两种主题模式生效，Dock、右键菜单、托盘菜单和设置面板同步切换。
- [ ] 背景透明度、图标尺寸、间距、整体缩放、内边距和圆角实时更新。
- [ ] 倒影和发光可调整、可关闭。
- [ ] 当前图标默认放大到150％，相邻图标和第二级邻居按距离轻微放大，布局同步让位且不重叠。
- [ ] 环境光色彩低饱和，边缘自然衰减，无彩色描边和底部亮线。
- [ ] Windows关闭动画后，悬停缩放停用。
- [ ] 设置中不存在“新图标默认外观”和单个“图标外观”选择。

### 窗口行为

- [ ] Dock可在所选显示器工作区自由拖动，并支持跨屏拖动。
- [ ] 固定后不能拖动，但图标仍可点击。
- [ ] 顶部、底部、左侧、右侧和屏幕中心按钮定位准确。
- [ ] 底部居中时，Dock底边距屏幕底部为当前任务栏高度的2.5倍。
- [ ] 左右定位切换纵向，上下定位切换横向。
- [ ] “自定义”只显示拖动状态，不会把Dock重新定位到底部。
- [ ] 鼠标穿透后，Dock下方窗口可直接接收鼠标。
- [ ] 托盘菜单可关闭穿透。
- [ ] Dock右键菜单和托盘菜单均为设置面板风格的黑底白字，选中、禁用和分隔线状态清晰。
- [ ] 系统托盘隐藏图标与BudsDock主程序图标一致，不显示Windows默认应用图标。
- [ ] `Ctrl＋Alt＋D`可关闭穿透并打开设置。
- [ ] 全屏视频、演示或游戏出现时Dock隐藏，退出全屏后恢复。

### 持久化与系统

- [ ] 重启BudsDock后位置、图标、主题和全部参数保持。
- [ ] 开机启动默认开启，关闭后启动项被移除。
- [ ] 移动便携目录后手动运行一次，启动项路径刷新。
- [ ] 中英文切换后设置页、托盘和内置图标名称同步更新。
- [ ] 导出`.budsdock`后在另一用户数据目录导入，自定义图标仍可显示。
- [ ] 配置损坏时应用创建恢复副本并使用默认配置启动。
- [ ] 未来版本配置创建`settings.unsupported-vX-*.json`后停止启动，不覆盖未知字段。
- [ ] 保存失败时页脚显示可点击的重试入口。
- [ ] 开机启动写入失败后复选框和配置恢复为实际关闭状态。

### 设置窗口交互与可访问性

- [ ] ComboBox点击文字、空白区和箭头均可展开；键盘可展开并使用方向键选择。
- [ ] 下拉框展开时首次按Esc只关闭下拉框，再次按Esc隐藏设置窗口。
- [ ] 标题栏最小化、最大化／还原、关闭、双击标题栏均可用。
- [ ] 四个导航入口支持鼠标、Tab焦点和`Ctrl＋1`至`Ctrl＋4`。
- [ ] 五个定位按钮具有可读名称、可见焦点和互斥选中状态。
- [ ] 滑块支持鼠标点击轨道、方向键调整和可见焦点。
- [ ] 640×480、820×540、960×680、1280×720DIP下无横向裁切；页面可纵向滚动。
- [ ] 100％、150％、200％DPI下标题栏命中区、滚动条和表单不重叠。
- [ ] 深色／浅色、中文／英文分别完成一次纯键盘导航和基础读屏检查。
