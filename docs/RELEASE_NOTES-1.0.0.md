# BudsDock 1.0.0

BudsDock 1.0.0是首个公开发布版本，提供Windows 11 x64单文件便携程序。

## 新增与优化

- 设置窗口完成响应式重做，支持640×480DIP至宽屏布局、四类设置导航和图标管理主从视图。
- Dock悬停默认放大至150％，相邻与第二级邻居按距离联动并让位。
- 图标光晕按图标像素自动取色，采用较大范围和较低亮度；安全边距覆盖最大图标、悬停和Dock缩放组合。
- Dock右键菜单与托盘菜单统一为设置面板风格的近黑底、白字、圆角、边框和清晰悬停状态。
- 系统托盘图标优先读取BudsDock主程序图标。
- 底部居中定位使Dock底边距屏幕底部保持当前底部任务栏高度的2.5倍。
- 增加真实保存状态、异步命令防重复、最终退出保存、开机启动失败回滚和鼠标穿透恢复提示。
- 配置加载增加规范化、版本门禁、迁移备份和导入事务保护。

## 验证

- Release构建：0个警告，0个错误。
- 自动化测试：32／32通过。
- 最终单文件冒烟测试：退出码0，WPF绑定错误日志0字节，配置SchemaVersion为2。

## 已知限制

- 仅支持Windows 11 x64和主显示器Dock。
- 当前未提供安装器、在线更新、代码签名、ARM64和多显示器Dock。
- 便携包内含.NET 10桌面运行时，因此目标电脑无需另行安装.NET。
