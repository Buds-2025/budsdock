# BudsDock 1.0.1视觉与交互规范

Dock以原始应用图标承担识别，底板使用中性深浅材质、细边缘高光与24DIP默认圆角。首次运行关闭倒影。设置统一使用原始图标，允许更换自定义图片，不再提供默认外观或单个图标样式选择。

深色窗口背景为`#0B0E13`，设置表面为`#181E27`，Dock表面为`#151B24`，主文字为`#F4F7FB`，强调色为`#7C9CFF`。浅色背景为`#F3F6FA`，表面与Dock为白色，主文字为`#172033`，强调色为`#365FC7`。具体资源以Theme.Dark.xaml和Theme.Light.xaml为准，主题可跟随Windows。

默认图标54DIP，间距12DIP，内边距12DIP，底板不透明度88％。工作室预设使用135％悬停倍率与较低环境光，简约预设采用44DIP图标并关闭动效、倒影与环境光，经典预设保留倒影与150％悬停倍率。切换预设只修改外观参数，不修改项目、开机启动或显示器选择。

悬停保持图标轮廓清晰，使用缩放与相邻图标让位表达反馈。移除图标上的彩色阴影、双层高亮和底部亮线。环境光使用保留约45％原色差异的低饱和色彩，位于图标下方，透明度最多30％，边缘渐隐。约220毫秒淡入、320毫秒淡出。设置或Windows关闭动画后停止悬停动效。

设置窗口默认960×680DIP，最小640×480DIP；900DIP以下改为顶部导航与单栏主从布局。图标列表支持名称及路径搜索，搜索不影响Dock；无结果时提供文字提示。Ctrl＋F进入搜索，Ctrl＋1至Ctrl＋4切换页面，Esc优先关闭下拉框、返回列表或关闭设置。

Dock支持鼠标拖动排序，图标右键提供打开、编辑、上移及下移。空白区域可拖动整个Dock，位置固定只限制窗口移动。窗口适配所选显示器的工作区；超大Dock统一缩小，避免部分项目离开屏幕。图标保留可访问名称与键盘焦点反馈，工具提示随主题切换。
