# BudsDock视觉规范

## 视觉方向

界面参照`reference-dock.png`中的低饱和悬浮图标栏：底板存在感低，图标承担主要识别任务，倒影只用于建立层次。设置窗口使用平面层级，减少卡片嵌套和装饰性玻璃效果。

本规范参考了公开的Impeccable UI/UX设计Skill所强调的排版、色彩、空间、动效、交互和可访问性规则，并根据Windows 11桌面应用场景调整。该Skill采用Apache-2.0许可；本项目没有复制其受保护示例界面或捆绑脚本。

## 颜色

深色主题使用带蓝紫倾向的中性色：

- 窗口背景：`#101216`
- 设置表面：`#1B2028`
- Dock表面：`#222631`
- 主文字：`#F1F3FA`
- 次文字：`#B7BECD`
- 强调色：`#8EA6FF`
- 图标前景色：`#F1F3FA`
- 圆角底片：`#3C46566E`

浅色主题使用同色相的浅中性色：

- 窗口背景：`#F5F7FA`
- 设置表面：`#FFFFFF`
- Dock表面：`#F4F6FB`，默认表面不透明度88％，保证桌面壁纸变化时图标仍有稳定底色。
- 主文字：`#202431`
- 次文字：`#5D667A`
- 强调色：`#3E5BC2`
- 图标前景色：`#202431`
- 圆角底片：`#B9C6E0`
不使用纯黑、纯白和高饱和霓虹渐变。强调色主要用于选中、悬停、焦点和单色图标。

## 空间与尺寸

- 默认Dock表面透明度：88％，可通过设置页调整。
- 默认图标尺寸：54px，可调范围28～112px。
- 默认图标间距：12px，可调范围0～48px。
- 默认Dock内边距：12px，可调范围4～36px。
- 默认圆角：18px，可调范围0～36px。
- Dock整体缩放：65％～180％。
- 设置窗口默认960×680DIP，最小640×480DIP，标题栏48DIP；所在显示器工作区四周保留16DIP安全边距。
- 900DIP及以上使用200DIP左侧导航、280DIP图标列表和自适应详情区。900DIP以下改用顶部导航，图标列表与详情采用单栏主从切换。
- 二级页面卡片随可用宽度展开，内容区最大1100DIP；在1280DIP窗口内可完整铺开，在2K、4K窗口中避免滑块被无限拉长。
- 页面内容边距为28/24DIP；卡片默认10DIP圆角，控件默认8DIP圆角。
- 局部间距遵循4/8/16/24px节奏，避免使用负边距制造视觉错位。

## 图标

- 原图：保持应用图标原始轮廓。
- 圆角底片：使用低对比度主题底片，图标内缩8px。
- 单色图标：将图标作为强调色不透明蒙版。
- 倒影默认高度为图标尺寸的26％，仅在横向Dock显示；使用自上而下渐隐，不与图标本体竞争。

## 动效

- 当前图标默认悬停缩放至150％，相邻图标缩放至116％，第二级邻居缩放至约105.6％；RenderTransform只参与合成，并通过独立位移让相邻图标让位，避免逐帧重新测量布局。
- 发光颜色从每个图标的高饱和像素加权提取；内置图标使用各自的品牌色，紧凑外发光与径向环境光晕叠加，BlurRadius随图标尺寸在16～52px内联动。
- 放大进入使用170ms四次缓出曲线，离开使用230ms三次缓出曲线；光晕使用145ms淡入和220ms淡出。
- 动效关闭后所有图标保持100％比例。
- Windows关闭客户端区域动画时，BudsDock同步停用悬停放大。
- Dock与托盘右键菜单使用深色设置面板的近黑表面、白色文字、圆角、描边和悬停层级。
- 不使用弹跳和弹性缓动，不持续播放无意义动画。

## 交互与可访问性

- 图标采用单击启动，并提供名称工具提示。
- 设置窗口中的主要控件保持明确标签和可见悬停状态。
- 标题栏最小化、最大化／还原和关闭按钮均位于客户端命中区，并提供本地化UIA名称。
- ComboBox完整表面均可展开，支持键盘展开、方向键选择和Esc优先关闭下拉框。
- 窄屏图标详情提供返回按钮；导航支持`Ctrl＋1`至`Ctrl＋4`。
- 五个定位按钮使用单选语义和单向选中绑定，命令是定位设置的唯一写入口；自定义位置只显示拖动状态。
- 固定位置和鼠标穿透为两个独立设置。
- 鼠标穿透始终保留托盘入口和全局快捷键恢复路径。
- 高权限启动必须经过Windows UAC确认。
- 中英文字符串位于独立资源字典，避免硬编码布局依赖。
- 页脚只显示真实保存状态和版本号，不使用装饰性状态指示。
