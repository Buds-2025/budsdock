# BudsDock 1.0.1升级验收报告

本版完成了桌面启动体验、设置简化、多显示器定位、图标加载和发行体积优化。沿用WPF、WinForms托盘与原生Windows接口，未增加第三方NuGet依赖。支持范围为Windows 11 x64。

## 交付内容

| 方面 | 交付结果 |
| --- | --- |
| 外观 | 工作室、简约、经典预设；细边缘高光；首次运行默认关闭倒影；深浅主题及跟随Windows |
| 悬停 | 移除彩色轮廓阴影、双层高亮和底部亮线；使用低饱和环境光；约220毫秒淡入、320毫秒淡出 |
| 设置简化 | 移除新图标默认外观与单个图标外观选择；统一原图；旧配置自动迁移，自定义图片路径保留 |
| 功能 | 添加文件夹；按名称和路径搜索；Dock内拖动排序；图标右键打开、编辑、上移、下移 |
| 交互 | 搜索不影响Dock；搜索无结果提示；Ctrl＋F搜索；Dock方向键导航；保留原有Esc、页签快捷键与穿透恢复 |
| 显示器 | 选择显示器、跨屏拖动、相对坐标记忆、断连回主屏、超大Dock自动适配；全屏避让限定同一显示器 |
| 性能 | 两个后台图标解码槽；图片最长边256像素；256项FIFO缓存；优先获取高分辨率Shell图标；延迟创建设置窗口 |
| 体积 | 移除未使用的Windows SDK和WinRT投影程序集；Portable中英文资源筛选；新增Compact发行包 |
| 可靠性 | 非数值外观参数保护；集合清空后解除旧订阅；异步图标状态不触发保存；修复跨DPI定位请求丢弃与拖动回跳 |

图标环境光最高透明度限制为30％，默认设置的目标透明度约14％，同时通过渐变遮罩继续衰减。图标轮廓保持清晰，悬停反馈主要来自缩放和相邻图标让位。原始图标的品牌颜色保留。

## 测试与审查

Release编译通过，无警告、无错误。45项自动化测试通过，包含配置迁移、损坏恢复、未来版本保护、并发保存、导入回滚、解码尺寸、资源重复键及旧图标模式迁移。

两种实际发行包均执行960×680深色中文与640×480浅色英文检查，共4种组合。每次检查在真实WPF窗口中验证搜索隔离、图标排序、300个并发图标加载和256项缓存上限，并渲染四个设置页面及Dock静止、悬停截图。每次启动结束检查WPF绑定日志，并要求程序以退出码0结束。脚本为`scripts/verify_release.ps1`，独立数据与截图位于项目`artifacts/validation`。

通过Windows界面自动化实测了Dock内鼠标拖动排序，随后核对配置文件顺序确实改变；右键菜单能显示打开、编辑图标、上移和下移。普通应用、文件夹和快捷方式的分类与存储由回归测试验证。未把模拟图标测试当作对所有第三方程序启动的保证。

三位Agent分别进行交互与多屏、运行时、产品与发布方面的对抗性审查。发现并修复了DPI变化时回跳或丢弃纠正定位、跨小屏拖动归一化时机错误、目标路径修改未同步类型、详情预览不刷新、异步缓存突破容量、路径大小写导致占位图不刷新等问题。最终复查未发现阻断问题。Shell图标透明度另在本机实际提取explorer.exe的256×256图像验证，角落alpha为0。

## 性能测量口径

本机Windows 11、.NET 10.0.10，同一台机器顺序启动基线与候选版，均使用5个默认图标和已创建的设置窗口。启动后等待3秒，再采样5秒。该测试避免修改真实配置及开机启动项。

| 本机单次采样 | 1.0.0基线 | 1.0.1候选 |
| --- | ---: | ---: |
| 进程私有字节 | 131,678,208 | 124,321,792 |
| 工作集字节 | 163,454,976 | 163,258,368 |
| 5秒CPU时间增量 | 0毫秒 | 0毫秒 |
| 句柄数量 | 876 | 870 |

这些是本机单次采样值，受文件缓存、GC和系统调度影响；0毫秒表示采样精度下没有可测增量。不能据此推断所有机器的启动时间或长期内存占用。计时工具的InputIdle也不等于首帧完整可交互时间，因此不将其写为启动提速承诺。性能数据采自移除两组图标样式选择前的候选版，最终版本未重新测量长期资源占用。

测量脚本为`scripts/measure_idle.ps1`，原始记录位于`artifacts/benchmarks`。发布体积记录以`outputs`中对应JSON与SHA256文件为准。

## 兼容与验证边界

多屏坐标使用显示器内DIP计算，再将工作区原点转换为物理像素；DPI变化后重新安排定位，拖动期间暂停自动定位。当前环境没有完成真实双屏混合DPI、显卡切换、远程桌面及长时间休眠恢复的完整测试。这些场景仍应在目标硬件上核查。

不包含每屏一个Dock、系统模糊材质、原生ARM64、商店应用枚举、自动隐藏、运行中窗口指示器或在线更新。配置格式继续兼容1.0.0；被移除的图标模式统一迁移为原图。旧版发布记录可在GitHub Release查阅；本地保留当前发行包、最终验证记录与性能测量依据。

## 技术依据

目标框架采用微软为WPF推荐的Windows TFM，未使用WinRT API时无需携带版本化Windows SDK投影，参见[目标框架文档](https://learn.microsoft.com/en-us/dotnet/standard/frameworks)。高分辨率图标通过[IShellItemImageFactory.GetImage](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ishellitemimagefactory-getimage)获取，并在后台执行可能阻塞的Shell操作。应用清单使用[Windows 10与11支持标识](https://learn.microsoft.com/en-us/windows/win32/sbscs/application-manifests)。未启用WPF程序集裁剪，相关限制见[dotnet/wpf官方问题记录](https://github.com/dotnet/wpf/issues/3811)。对外引用这些兼容性和测量结论时，请结合对应官方来源及目标电脑实测结果核查。
