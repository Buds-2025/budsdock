# BudsDock设置界面重做说明

> 历史设计记录：本文描述第一轮视觉调整。当前设置窗口已完成响应式结构、保存状态、完整表面ComboBox、标题栏交互和图标管理主从布局重做，现行规范见`docs/DESIGN.md`与`docs/TESTING.md`。

## 重做目标

本次重做针对设置界面的三个问题：外层描边不均匀、视觉层级不足、深浅主题之间缺少统一产品语言。布局结构保持原有信息架构，重点重做视觉基础。

## 视觉逻辑

- 采用“画布、导航、内容、面板、控件”五层结构。
- 去除Window最外层描边，避免圆角窗口在不同DPI下出现不均匀亮边。
- 卡片使用表面色差建立层级，不依赖一圈高对比描边。
- 输入控件默认无描边，仅在悬停和键盘聚焦时显示边界。
- 导航选中状态使用浅色背景和左侧3px强调条，不使用虚线焦点框。
- 标题栏按钮使用低存在感样式，悬停时才显示背景反馈。
- 圆角收敛为：控件8px、卡片10px、窗口12px、提示框6px。
- 间距收敛为4/8/16/24/32px节奏。

## 字体层级

- 基础字体：Segoe UI Variable Text，并以Microsoft YaHei UI作为中文回退。
- 显示标题：Segoe UI Variable Display，并以Microsoft YaHei UI作为中文回退。
- 页面标题：20px，SemiBold。
- 标题栏页面名：16px，SemiBold。
- 区块标题：14px，SemiBold。
- 正文：13px。
- 辅助说明：12px。

减少14、15、16px连续中间字号，避免标题层级挤在一起。

## 具体修复

- 设置窗口根Border移除BorderBrush和BorderThickness，并启用圆角裁剪。
- 侧边栏移除右侧分割线，使用背景色差分隔导航和内容。
- CardBorder移除默认描边。
- ModernButton默认无描边，悬停以背景色和强调色反馈。
- TextBox和ComboBox默认无描边，键盘聚焦时显示强调色边界。
- 自定义Slider和ComboBox模板，消除系统Aero模板在深色主题下的浅色残留。
- ComboBoxItem增加高亮和选中态。
- ToolTip使用6px圆角和主题表面。
- 窗口控制按钮独立于内容按钮样式。
- 设置页内容外边距统一为32/24px，图标管理页列表列宽调整为312px，列间距16px。
- 去除帮助文本负边距和表单字段的不规则间距。
